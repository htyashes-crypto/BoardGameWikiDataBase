# 蓝图类管理

![img-1](./fig-blueprint-mgmt-class-01.png)

点击“蓝图类管理”页签可跳转到蓝图类管理界面，在此界面可以看到工程内的所有蓝图类。

![img-2](./fig-blueprint-mgmt-class-02.png)

点击任意蓝图类的右上角按钮，可对该蓝图类进行打开、导出C#、删除操作。

![img-3](./fig-blueprint-mgmt-class-03.png)

在蓝图管理界面可以对蓝图进行分区管理，点击“RegionEdit”可进入分区调整模式，此时可以拖动蓝图到其他分区、新建分区、删除分区、修改分区名称、调整分区顺序。
