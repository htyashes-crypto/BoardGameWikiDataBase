# 页签管理

![img-1](./fig-edit-window-tab-management-01.png)

编辑窗口是由上方的页签区域和下方内容区域两部分组成的。每当用户从侧边栏打开的一个新的配置界面时，都会在编辑窗口新增一个页签，并显示对应的内容界面。

![img-2](./fig-edit-window-tab-management-02.png)

用户可以通过点击上方不同页签在多个配置界面之间快速跳转。

![img-3](./fig-edit-window-tab-management-03.png)

点击一个页签右侧的“X”按钮可以将该页签以及对应的配置界面从编辑窗口中移除。
